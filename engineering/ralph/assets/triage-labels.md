# Triage labels

Five canonical roles and their label strings for this repo:

| Role | Label |
|------|-------|
| Maintainer needs to evaluate | `needs-triage` |
| Waiting on reporter | `needs-info` |
| Fully specified — AFK agent can pick up | `ready-for-agent` |
| Needs human implementation | `ready-for-human` |
| Will not be actioned | `wontfix` |

> Edit this file to map roles to your actual label names if they differ from the defaults.
